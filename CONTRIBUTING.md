# Contributing

Thanks for your interest in this project.

## Reporting bugs and requesting features

Open an [issue](https://github.com/siddak1234/heirloom_scents_website/issues) using the appropriate
template. Include enough detail to reproduce the problem: what you did, what you expected, and what
actually happened.

## Pull requests

1. Open an issue first for anything beyond a small fix, so the approach can be agreed on before work starts.
2. Branch off `main` — use a short, descriptive branch name (`fix/broken-nav-link`, `feat/contact-form`).
3. Keep each pull request focused on one change. Unrelated cleanups belong in their own PR.
4. Write clear commit messages: a short imperative subject line, and a body explaining *why* when it isn't obvious.
5. Fill in the pull request template and link the issue it closes.
